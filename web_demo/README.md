# Vital Wristband Command Center

Interactive demo of an ESP32 fall-detection and vitals wristband. The page replays the firmware's
simulation scenario in your browser: the fall state machine, live vitals, the caregiver alert log,
and a clickable wristband (button A cancels a fall, button B confirms medication).

Source code, firmware and ML pipeline: https://github.com/f20230104-dotcom/Vital-armband
